# tahasilat-portfolio

Personal portfolio site for Taha Silat. Plain HTML, CSS and JavaScript — no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Deploy

Works as-is on GitHub Pages: push to GitHub, then enable Pages under
**Settings → Pages → Deploy from branch → `main` / root**.
